# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Midad**, please send an email to the project maintainers. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues.

### What to Include in Your Report:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce the issue (proof-of-concept script, reproduction repository, or sample inputs).
- Any proposed remediation if known.
